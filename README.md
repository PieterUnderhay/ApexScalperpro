# ApexScalperpro

Version 0.5 retains the Version 0.4 Decision Engine framework and evaluates BUY, SELL, or NO TRADE opportunities using confirmed closed-bar signals. It adds configurable EMA/ATR and directional-DI separation filters plus a decision-confidence gate to reduce weak and intrabar-flickering signals. Trading remains disabled; the EA only displays decision telemetry on the dashboard.
